**目标：** 修复 2026-10-17 审计发现的软件问题，恢复可验证的数据链路；外部账号失效须明确反馈并提供操作入口，不把失败当成分析完成。

**方案：** 保持现有 pipeline/兜底引擎与路由结构，在公共配置、状态、任务及工具协议边界修正缺陷。沿用 SQLite 和 Vue Composition API，不引入新框架。

**验收：** 配置可保存且重启不丢失；禁用 Agent 不运行；不同分析目标不串任务；所有任务响应包含恢复所需记录 ID；失败统一到 error；过期运行记录可恢复；模型消息配对和反思完整有效；前端场景协议正确；测试不意外访问真实服务。

- [ ] 公共专家执行：修复自反思模板/Completion/重试；工具摘要逐条保留响应；基金代码检查支持字典参数；统一执行器正确保存历史。新增完整 Mock 回归，先失败再修。
- [ ] 分析入口：债券/情景注入对应启用 Agent 提示词；热点/市场情报/增强策略遵守禁用；失败状态向外传播；热点历史动态 ID。新增路由失败与配置测试。
- [ ] 导入和依赖：统一 services 旧/新路径对象身份；修复回归测试日期/响应协议/开关替身；核对东方财富新接口，提供可运行数据查询或明确失败；天天基金登录失效显示可操作状态，不自动代用户授权。
- [ ] 数据与任务：默认提示词只插入不覆盖；稳定专家 key，补齐 loader 字段与数据库隔离缓存；目标维度去重并保存 record/history ID；清理过期分析记录与对应日志；新库按名称选择默认指数 Agent。
- [ ] 前端：情景发送 key/parameter/custom_scenario；任务重复提交可恢复正确记录；轮询有总期限；新增 API/交互回归。
- [ ] 验收：各组定向测试→完整后端/前端测试→前端构建到临时目录→只读最小服务验证→代码评审→更新审计结果。若登录仍需用户操作，明确记录剩余外部步骤。
