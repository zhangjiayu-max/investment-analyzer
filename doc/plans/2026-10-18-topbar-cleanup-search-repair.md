# 顶栏去重与搜索修复计划

**目标：** 桌面只保留顶部投资语录；融资指标显示真实数据日期；全局搜索能找到持仓与最新指数估值。

**方案：** 删除 Home 的蓝色语录栏及请求、定时器和样式。TickerBar 独立加载语录池，在本地每 10 秒轮换、支持点击换句；融资数据每分钟独立刷新，不受看板接口影响。融资摘要增加交易日期和可用状态，明确仅为沪市日频辅助指标。全局搜索读取真实持仓表，指数按代码与指标保留最新记录；结果页阻止过期请求覆盖并安全高亮。

**技术：** Vue 3 / Vitest / FastAPI / SQLite / pytest。

- [x] 修改 `frontend/src/components/finance/TickerBar.vue`、`frontend/src/views/Home.vue`，保留顶部单一入口；复用原 20 条备用文案。

## 边界

融资余额是沪市日频数据，周末、节假日不变化属于正常情况；不将其描述为实时新闻或全市场机构净流入。保持移动端原布局，避免修改用户其他进行中的资产与财务变更。

## 验证结果

- 前端定向与相关回归：36 项通过。
- 后端顶栏与搜索回归：16 项通过；包含空值、NaN、零余额和负余额的上游融资数据测试。
- 独立代码审查：发现的空余额误算问题已修复并复审通过。
- 真实接口：100 条语录；融资日期 2026-10-16、近五日变化 -331.87 亿元；指数代码搜索仅返回最新指标。
- 浏览器：蓝色语录栏为 0 个、顶部语录为 1 个；回车和按钮搜索均可用；1000px 桌面窗口搜索可见、页面无横向溢出。

## 后续调整：融资数据收进信息图标

用户希望顶部更简洁，融资数值不再常驻。TickerBar 只保留信息图标，复用 TermTooltip 的 Teleport 浮层展示数值、日期和用途说明，支持悬停、点击、键盘聚焦，并可按 Escape 或点击外部关闭。此前仅使用原生 title，替换为真正的浮层，避免提示显示不可靠。TermTooltip 增加默认关闭的 iconOnly 属性和 trigger 插槽，保留其他页面现有问号外观。
