# 智能补仓与机会雷达 P0 治理实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 统一估值百分位口径，以真实现金和组合资金池约束智能补仓金额，并让机会雷达按信号来源和独立样本提供可信回测统计。

**架构：** 在数据库估值出口建立统一百分位契约；在单标的计划生成后新增纯函数式组合预算分配层；所有持久化和候选生成只消费分配后的最终金额。机会雷达保持现有评分不变，只显式传播来源并在数据层聚合独立样本。

**技术栈：** Python 3.11、pytest、sqlite3、FastAPI 现有路由协议。

---

- `backend/db/valuations.py`：百分位解析和所有估值结果出口标准化。

- [ ] **Step 3：实现纯函数预算分配器**

```python
def _allocate_portfolio_budget(plans: list[dict], monthly_budget: float) -> dict:
    eligible = [p for p in plans if (p.get("safety") or {}).get("can_add", True)]
    total_raw = sum(max(0.0, p.get("final_suggested_amount", 0) or 0) for p in eligible)
    scale = min(1.0, monthly_budget / total_raw) if total_raw else 0.0
    for plan in plans:
        raw = max(0.0, plan.get("final_suggested_amount", 0) or 0)
        plan["raw_suggested_amount"] = round(raw, 2)
        plan["budget_scale"] = round(scale, 4) if plan in eligible else 0.0
        plan["final_suggested_amount"] = round(raw * scale, 2) if plan in eligible else 0.0
    allocated = round(sum(p["final_suggested_amount"] for p in plans), 2)
    return {
        "monthly_budget": round(max(0.0, monthly_budget), 2),
        "total_raw_demand": round(total_raw, 2),
        "allocated_amount": allocated,
        "allocation_scale": round(scale, 4),
        "budget_exhausted": total_raw > monthly_budget,
        "budget_basis": "cash_plus_monthly_inflow",
    }
```

实现时处理分币舍入尾差，确保合计不超过预算。
