## 二、不足分析（按优先级）

### P0 闭环断点（影响系统可信度）

#### P0-1 决策→执行→真实盈亏 回写缺失
- **现状**：`routers/decision/suggestion_accuracy.py` 仅统计到 verdict 阶段
- **影响**：建议准确率"自我感觉良好"，无法用真实账户盈亏校准
- **方案**：新增 `decision_execution_log` 表 + API + 前端回写入口

#### P0-2 评估未常态化自动触发
- **现状**：`conversation_evaluator.evaluate()` 需显式调用
- **影响**：每天对话没有自动质量评分，BadCase发现滞后
- **方案**：在 orchestrator 对话完成钩子自动触发评估（开关控制，默认开）

#### P0-3 行为数据未反推KYC画像
- **现状**：`kyc.py` 6维度全靠问卷自报
- **影响**：用户说的风险偏好与实际行为脱节
- **方案**：从交易记录反推行为画像（买卖频率/持仓周期/止损纪律），与问卷画像融合

#### P0-4 在线估值兜底不入库
- **现状**：`db/valuations.py:610` 注释"akshare/ttfund查到的实时估值不入库"
- **影响**：重复查询浪费调用，无法做估值历史趋势分析
- **方案**：在线兜底结果写入 `valuations_online` 表，7天TTL

#### P0-5 回测未扣交易成本
- **现状**：`services/strategy/strategy_library.py` 未扣手续费/滑点/印花税
- **影响**：回测收益系统性高估，高频策略偏差更大
- **方案**：在回测引擎加入交易成本模型（佣金/印花税/过户费/滑点）

### P1 实时性短板（影响盘中体验）

#### P1-6 无WebSocket实时行情推送
- **现状**：仅SSE单向推送alert文本
- **方案**：本次先增强SSE携带数据，WebSocket作为后续大工程

#### P1-7 新闻时效最差30分钟
- **现状**：事件雷达每日3次定时扫描 + 30分钟缓存
- **方案**：SSE通知携带数据，前端收到直接展示，无需二次拉取

#### P1-8 北向资金永久缺失 + 龙虎榜未实现
- **现状**：`institutional_flow.py:11` 龙虎榜注释"P1扩展"未实现
- **方案**：实现龙虎榜机构席位数据采集（akshare `stock_lhb_detail_em`）

### P2 专家覆盖盲区

#### P2-9 缺5类关键专家
- 衍生品/可转债专家、量化/技术面专家、海外资产专家、税务/传承专家、行业细分专家
- **方案**：本次先补可转债专家 + 量化技术面专家（最高频需求）

#### P2-10 并行度硬编码4
- **现状**：`orchestrator.py` `max_workers=min(len(routed_specialists), 4)`，但专家上限已到5
- **方案**：改为动态 `min(len(routed_specialists), 5)`

### P3 RAG与知识库短板

#### P3-11 RAG召回率整体偏低
- 4个领域Recall仅0.50-0.60

#### P3-12 Reranker默认关闭
- **方案**：开启CrossEncoder重排序，增加超时保护

#### P3-13 多模态知识缺失
- **方案**：后续大工程，本次不做

### P4 前端工程化短板

#### P4-14 无前端错误监控/性能采集
- **现状**：仅console.error，无上报
- **方案**：自建轻量错误上报 + Web Vitals采集（不引入Sentry重依赖）

#### P4-15 巨型组件 + 巨型API文件
- **方案**：后续重构，本次不做

#### P4-16 移动端定制不足
- **方案**：后续大工程，本次不做

#### P4-17 图表技术栈不统一
- **现状**：ECharts为主，但有手写SVG饼图/趋势图，`lightweight-charts` 依赖冗余
- **方案**：移除手写SVG，统一ECharts；移除 `lightweight-charts` 冗余依赖

### P5 可观测性与反哺闭环

#### P5-18 TaskDetail不显示Agent执行细节
- **现状**：仅4步固定流程
- **方案**：增强TaskDetail展示工具调用/专家编排/思考流

#### P5-19 评估结果未反哺专家权重
- **现状**：进化机制识别"需调优专家"，但未自动调整路由权重
- **方案**：评估低分专家累计N次后，路由时降权（带恢复机制）

#### P5-20 无A/B测试与评估联动
- **方案**：后续做，本次不做
