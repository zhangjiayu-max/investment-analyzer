## 框架改造补充（用户继续授权深入优化及推送远程）

保留现有 FastAPI / Vue / Pipeline。单纯提高输出限制会保留冗余，整体替换 Agent 框架成本高且不能解决证据契约问题；本次沿现有阶段边界集中改造数据流。

- 原始工具证据只在本轮执行记录中完整保存；模型发送层创建独立视图，按总字符额度与单工具额度压缩，并对重复工具结果引用来源编号，不能截断 JSON 或破坏 tool_call_id / reasoning_content。
