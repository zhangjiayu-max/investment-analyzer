# 系统治理修复与升级复查计划

依据用户已确认的全功能审查报告实施。先修复已复现缺陷，再验证和整理升级项；不执行生产数据变更、真实 LLM 评测或发布。

- 配置与成本：保留配置/Prompt，验证版本归属，修接口、Trace、统计窗口与状态。
- 评测与质量：真实执行和候选 Prompt、任务终态、统一评分、快照、幂等和失败重试。
- 健康分与回测：任务/DTO、数据不足状态、指标和现金流口径、参数校验与历史保存。
- 数据与埋点：按标的覆盖、来源新鲜度规则、会话身份、有效停留和正确计数。
- 能力与实验：契约去重、启用/参数/副作用检查；Shadow先接通明确支持的对话入口，抽样和预算保护、失败留痕，保持现有开关不自动启用。

每个领域增加有意义的隔离回归，先观察失败再修复。并行修改按领域分配文件，集成后复核差异，运行相关后端测试、前端测试和临时目录构建。最后逐项核对13项治理功能并记录剩余升级建议和外部集成验证边界。
