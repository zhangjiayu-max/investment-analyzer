# 家庭资产汇总与提示气泡修复计划

**目标**：修复家庭财务提示被卡片裁剪；总资产与持仓管理的全部账户口径一致。

**依据**：持仓属于 default 用户下的小鱼儿、花无缺账户；现金按账户名称保存在 portfolio_cash.user_id。家庭财务此前误取 legacy default 现金。提示使用 absolute 定位，祖先卡片与主区域有 overflow 裁剪。

**实现**：使用共享账户现金汇总，default 家庭聚合现有两个家庭账户；缺少分账户现金记录的旧库兼容原 default 余额。其他 user_id 继续隔离，禁止全表求和。账户筛选只计算该账户。持仓汇总、家庭总览、现金流和诊断复用同一来源，不修改实际余额。总览展示账户名称及持仓加现金构成，不将已登记投资资产当作完整家庭净资产。

**提示**：挂载到 body，使用视口定位并按空间翻转、限制宽度；保留卡片圆角裁剪，支持键盘焦点与触屏点击，离开或滚动后关闭/重新定位。

- [x] 后端回归先复现家庭账户现金漏算、legacy default 混入、筛选及用户隔离。
- [x] 修复共享汇总并联动总览、现金流与投资金额限制；压力测试、配置、预测与资金桶同步使用同一现金口径。
- [x] 前端修复气泡，补充资产构成说明与交互回归；旧库打开持仓页不会通过辅助请求创建空账户并丢失旧余额口径。
- [x] 相关测试、生产构建与浏览器验证；更新本机静态资源供实际页面使用。

验证：后端临时数据库用不同用户、两家庭账户、残留 default 余额；前端验证气泡传送至 body、边缘翻转、关闭及现金口径。浏览器验证真实页面悬浮显示完整和总资产分项可核对。

结果：后端相关测试 106 项通过，压力/配置原有测试更新迁移后导入和统一响应读取后额外 4 项通过；前端 62 项通过；Vite 生产构建成功并写入 static。浏览器实测家庭总览与持仓全部账户均为 1,027,648.22 元（持仓 521,749.83 + 分账户现金 505,898.39）；花无缺筛选为持仓 134,316.29 + 现金 1,631.03 = 135,947.32。风险损失比例同步为 5.3%。独立审查发现并修复可编辑标签跨用户读取现金、旧库辅助读取创建空账户两项问题。
