## 复核补充

- 历史 active 标签不证明 Prompt 已发布。默认评测始终读取生产配置；漂移需要显式重新发布，不通过迁移自动覆盖生产。
- 空 JSON、缺字段、布尔值、越界和非有限评分、缺评语均为评审错误。评审失败不等于低质量零分，也不应生成中性默认分。
- 回归的 error/skipped/new 不再计作 unchanged；统计恢复与首次执行一致。
- Shadow 删除实验不返还当天额度；旧实验记录标为未验证，不混入有效样本。
- 二八策略在债基缺报价时只沿用估值；等完整报价后才执行当月再平衡。股涨、股跌两个资金守恒回归均已覆盖。

## 验收边界和下一批优先级

1. **先补运行可靠性验收**：本轮本地热重载卡住已恢复，但退出卡住的根因尚未完成定位；应补后台任务关闭期限和热重载恢复验证。异步页面还缺统一加载、超时和错误恢复提示。源码和隔离组件/API 验证不等同于全部 13 页操作已重新通过浏览器验收。
2. **优先升级评测与发布一致性**：冻结外部证据，统一 Agent 管理和评测版本发布历史，传播多进程缓存失效，建立固定回归集和发布前后质量/成本对比。
3. **再升级数据治理闭环**：按交易日和来源定义 SLA，缺失标的关联受影响分析，提供修复和复验入口。
4. **再扩展分析深度**：XIRR、多资产回测、混合基金穿透、更多 Shadow 类型；扩展前保留“不支持/数据不足”的诚实状态。
5. **完善运营闭环与性能**：Bad Case 负责人及复测关闭、业务漏斗、供应商账单对账、图表包拆分。

历史缺失输入无法追溯恢复；无法确定评分标准的旧分数保留不确定性；旧回测不伪装成新方法结果。Shadow 本轮仅接通普通 Agent 对话，未自动打开全局开关；A/B 已对齐用例和本地证据，仍未冻结外部实时行情。
